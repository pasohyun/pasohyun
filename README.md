## 🚀 Key Projects

### 🎵 [F-Sync AI Agent — K-POP 팬 반응 NLP Gap 분석](https://github.com/pasohyun/fsync-ai-agent) `🟢 진행중`
- **Role**: PR/마케팅 분석 프레임 설계, 바이럴 지수 산출 로직, SNS 빅데이터 전처리 (FNC 엔터테인먼트 미래내일일경험 협업)
- **Focus**: N.Flying 「환절기」 대상으로 기획 의도(보도자료·A&R 자료)와 팬 반응(유튜브 댓글)의 Gap을 NLP로 수치화. 10.8만 건 댓글 라벨링, multilingual-e5-large 기반 멀티라벨 분류 모델 학습, 골드셋 검증을 통한 라벨링 품질 관리 수행.

### 🔬 [FSL2 실시간 가격 모니터링 플랫폼](https://github.com/pasohyun/libre-price-monitor-client)
- **Role**: 실질 단가 산출 로직 설계 및 자동화 대시보드 구축 (대웅제약 장학 프로젝트)
- **Impact**: Holt 추세예측 + MAD z-score 기반 선제적 이상 가격 탐지 체계 설계로 일일 모니터링 시간을 2시간에서 10분으로 단축, **외주 대비 약 3,000만 원 비용 절감** 달성.

### 💊 [Yak-Sok (약-속) — 중소병원용 AI 재고 최적화 솔루션](https://github.com/pasohyun/YakSok)
- **Role**: AI 기반 재고 관리 로직 설계 및 수요 민감도 분석 (대웅제약 해커톤 & 국제 캡스톤)
- **Impact**: **3-Tier 아키텍처와 Gemini API를 연동**한 실시간 자동 발주 파이프라인 구축. 중소형 의료기관의 자원 배분 효율 극대화 제안.

### 📈 [자산 배분 모델 기반 주식 입문자 학습용 게임](https://github.com/pasohyun/26-1-Bitamin-project)
- **Role**: HMM 거시국면 판독 모델링, PPO·A2C 강화학습 앙상블 자산 배분 로직 설계 (BITAmin 16기 자유 테마 프로젝트)
- **Impact**: Walk-Forward 백테스트 기준 **Sharpe 1.31·CAGR 14.8%**로 SPY 벤치마크(Sharpe 0.79·CAGR 12.9%) 상회. SHAP 기반 XAI와 LLM(Gemini)을 연결해 투자 초보자용 학습 게임으로 구현.
